# Topics

The Security &amp; Privacy Reading Group solicits materials on any topic related to information security, cryptography or privacy. These include:

- Access Control & Authorisation Systems
- Applied Cryptography (the use of crypto in protocols and systems)
- Big Data & Data Mining
- Cryptographic Primitives
- Cyber&ndash;Physical Systems (IoT, ICS, medical devices, vehicles, etc.)
- Differential Privacy
- Distributed Systems Security
- Forensics
- Formal Methods for Security
- General Software Security
- Machine Learning Privacy (Federated Learning, Synthetic Data, etc.)
- Hardware Security
- Homomorphic Encryption
- Malware Analysis
- Network Security
- Operating System & Virtualisation Security
- Risk Management & Governance
- Secure Multi-Party Computation
- Security and Privacy Law & Regulation
- Security Operations & Incident Response
- Telecommunications & Physical Layer Security
- Trusted Computing and Confidential Computing

This list is not exhaustive. Feel free to nominate papers which are tangentially related.
